# Project 1: LED Control System

Difficulty: Beginner

## Objective
Blink an LED, read a button, and create a traffic-light sequence.

## Suggested components
Board, LEDs, resistors, button, breadboard.

## Workflow
Configure outputs, write a timing loop, and test button input.

## Deliverables
- Labelled circuit diagram
- Complete commented source code
- Test plan and observations
- Results, limitations and safety notes

## Assessment
Assess wiring accuracy, code clarity, correct operation, testing quality and documentation.
