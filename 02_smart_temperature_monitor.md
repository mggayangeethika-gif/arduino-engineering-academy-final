# Project 2: Smart Temperature Monitor

Difficulty: Beginner–Intermediate

## Objective
Read a temperature sensor and display measured values.

## Suggested components
Compatible sensor, board, jumper wires, optional display.

## Workflow
Check sensor voltage and library, read values, compare against a reference.

## Deliverables
- Labelled circuit diagram
- Complete commented source code
- Test plan and observations
- Results, limitations and safety notes

## Assessment
Assess wiring accuracy, code clarity, correct operation, testing quality and documentation.
