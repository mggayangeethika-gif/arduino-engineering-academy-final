# Project 3: Automatic Water Level Monitor

Difficulty: Intermediate

## Objective
Detect water level and trigger an alert or pump-control signal.

## Suggested components
Water sensor, buzzer, driver/relay and low-voltage pump.

## Workflow
Set thresholds and test alerts. Use a rated driver and separate supply for pumps.

## Deliverables
- Labelled circuit diagram
- Complete commented source code
- Test plan and observations
- Results, limitations and safety notes

## Assessment
Assess wiring accuracy, code clarity, correct operation, testing quality and documentation.
