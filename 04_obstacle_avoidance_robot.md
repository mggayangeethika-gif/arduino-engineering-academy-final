# Project 4: Obstacle Avoidance Robot

Difficulty: Intermediate

## Objective
Measure distance and control a two-motor robot.

## Suggested components
Ultrasonic sensor, motor driver, motors and chassis.

## Workflow
Read distance and command motors through a driver.

## Deliverables
- Labelled circuit diagram
- Complete commented source code
- Test plan and observations
- Results, limitations and safety notes

## Assessment
Assess wiring accuracy, code clarity, correct operation, testing quality and documentation.
