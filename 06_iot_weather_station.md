# Project 6: IoT Weather Station

Difficulty: Advanced

## Objective
Send environmental readings to an online dashboard.

## Suggested components
ESP32, temperature/humidity sensor, Wi-Fi.

## Workflow
Connect, publish readings and inspect historical data.

## Deliverables
- Labelled circuit diagram
- Complete commented source code
- Test plan and observations
- Results, limitations and safety notes

## Assessment
Assess wiring accuracy, code clarity, correct operation, testing quality and documentation.
