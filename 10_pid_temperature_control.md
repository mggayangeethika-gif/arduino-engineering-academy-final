# Project 10: PID Temperature Control

Difficulty: Advanced

## Objective
Explore feedback control and PID response.

## Suggested components
Temperature sensor, low-voltage heater, driver.

## Workflow
Define setpoint, calculate error and tune cautiously.

## Deliverables
- Labelled circuit diagram
- Complete commented source code
- Test plan and observations
- Results, limitations and safety notes

## Assessment
Assess wiring accuracy, code clarity, correct operation, testing quality and documentation.
