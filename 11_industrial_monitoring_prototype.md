# Project 11: Industrial Monitoring Prototype

Difficulty: Advanced

## Objective
Monitor several sensor channels and report alarms.

## Suggested components
Multiple sensors, display/network module, power supply.

## Workflow
Define alarm limits and document failure behaviour.

## Deliverables
- Labelled circuit diagram
- Complete commented source code
- Test plan and observations
- Results, limitations and safety notes

## Assessment
Assess wiring accuracy, code clarity, correct operation, testing quality and documentation.
