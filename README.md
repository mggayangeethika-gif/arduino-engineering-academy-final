# Arduino Master Course — Single Folder Edition

All project files are placed directly inside this one folder. There are no nested folders.

## Open
1. Extract this ZIP.
2. Open this folder.
3. Open `index.html` in a modern browser.

## Upload to GitHub Pages
Upload all files in this folder to the root of your GitHub repository. Keep `index.html` at the repository root. Then go to Settings → Pages and publish from the main branch/root.

## Included
- `index.html` — website entry page
- `style.css` — website styling
- `app.js` — website interactions
- `curriculum.js` — 44 modules and 219 guided learning units
- `.ino` files — Arduino sample sketches
- `arduino_quick_reference.md` — quick reference
- project `.md` files — project briefs

## Important limitations
The in-browser editor is a text editor with basic structure checks, not an Arduino compiler or hardware simulator. Wokwi, Tinkercad and other simulators are external tools. Progress is saved in the current browser only.
